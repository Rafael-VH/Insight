Diagramas interactivos de la arquitectura del código

No se pudo cargar diagrams.json. Si abriste este archivo directamente (file://), el navegador bloquea la carga del manifiesto. Visita la página publicada en GitHub Pages o sirve la carpeta docs/ con un servidor local, por ejemplo npx serve docs.
Para agregar un diagrama: genera el HTML dentro de docs/ y registra una entrada en diagrams.json · Repositorio
